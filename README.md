# homebrew-mutantkit

Homebrew tap for [MutantKit](https://github.com/juntaki/mutantkit) -- trustworthy mutation
testing for Swift and Apple platforms.

## Install

```bash
brew install juntaki/mutantkit/mutantkit
```

## Usage

```bash
mutantkit doctor
mutantkit init
mutantkit plan
mutantkit run
```

Prebuilt for macOS arm64. Formula versions track
[GitHub Releases](https://github.com/juntaki/mutantkit/releases).
